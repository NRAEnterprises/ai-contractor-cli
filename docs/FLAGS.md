# Flags

`init`: `--project`, `--plan` (a path or `-` for stdin), `--provider`, `--interface`, `--output`, `--root`. Defaults are generic provider and CLI interface; project and plan are prompted/read from stdin if omitted.

`close`: session ID, `--evidence` file, `--status complete|halted` (default complete), `--root`.

`list`: `--status`, `--root`. `show` and `verify`: session ID, `--root`. `amend`: version, `--text`, `--root`.
