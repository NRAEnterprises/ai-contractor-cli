# FAQ

**Does this tool talk to an AI?** No. It generates local instructions and tracks sessions; it has no network or model integration.

**Can it guarantee model behavior?** No. Contracts guide behavior but are not technical enforcement.

**Why make web artifacts one-shot?** Browser chats generally cannot invoke a local close command. Their artifact therefore contains its own final audit requirement.

**Does close verify tests?** No. It records supplied evidence and warns about obvious incomplete language; evidence must be independently reviewed.

**Does init modify my project?** No. It writes session artifacts to its storage root and optional copies to `--output`.
