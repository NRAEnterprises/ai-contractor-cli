# Security policy

AI Contractor++ writes user-provided plans and generated artifacts to local files. Treat those files as potentially sensitive. Choose a private storage directory and apply appropriate operating-system permissions. The tool does not upload content or execute generated instructions.

Report vulnerabilities privately to the repository maintainer rather than publishing exploit details. Include affected version, impact, and reproduction steps. Do not submit credentials or private project material.

Generated contracts are prompts, not security controls. Review model output and retain normal backups, access controls, and software supply-chain safeguards.
